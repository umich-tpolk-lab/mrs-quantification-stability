# Data dictionary

The public release contains only variables required to reproduce the manuscript analyses.

## `participants.csv`

- `participant_id`: newly generated public identifier. It is not the study's internal identifier.
- `interval_years`: wave-1 to wave-2 interval in years, rounded to two decimal places. Used only for the shorter-interval sensitivity analysis.

## `mrs_measurements.csv`

One row per participant per session (56 participants × 2 sessions = 112 rows).

- `participant_id`: new public identifier.
- `session`: 1 or 2.
- Metabolite columns follow `{metabolite}_{quantification}_{hemisphere}{region}`.
  - Metabolites: `G` = GABA+, `GLX` = Glx.
  - Quantification: `UNC`, `CSF`, `TC`, `ATC`, `CR`.
  - Hemisphere: `L`, `R`.
  - Region: `AUD` = auditory, `SM` = sensorimotor, `VV` = ventral-visual.
- Tissue-fraction columns follow `{tissue}_FRA_{hemisphere}{region}`.
  - Tissues: `GM`, `WM`, `CSF`.

Bilateral values used in the analyses are generated by the R code after spectrum-level QC.

## `gannet_qc_metrics.csv`

One row per available spectrum (668 rows).

- `participant_id`, `session`, `region`, `hemisphere`: public keys.
- `lw_cr_hz`: creatine linewidth in Hz; >15 Hz is the main exclusion criterion.
- `fiterr_gaba_water`, `fiterr_gaba_cr`, `fiterr_glx_water`, `fiterr_glx_cr`: fit-error metrics. They are retained for reporting but are not used as an exclusion gate in the current manuscript.
- `gaba_cr`, `glx_cr`: Gannet concentration ratios used to identify non-physical fits with the >8 median-absolute-deviation rule.
- `snr_cr`: creatine signal-to-noise metric retained for QC reporting.

## Deliberately excluded

The public files exclude study/internal subject identifiers, RA names, visit dates and times, clinical/drug variables, recruitment fields, internal file paths, raw MRS filenames, and variables unrelated to this manuscript.
